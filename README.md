# Aman Yadav — Blue Tech Portfolio

A responsive, static portfolio website for Aman Yadav, Electronics and Communication Engineering.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser. Internet is needed for the Google Fonts; the site otherwise works without a build step.

## Personalize before publishing
Open `index.html` in a text editor and replace:
- `YOUR_EMAIL@example.com` with your real public email.
- `https://www.linkedin.com/` with your LinkedIn profile URL.
- `https://github.com/` with your GitHub profile URL.

Review the skills and project descriptions so they accurately represent your current work. Project status labels currently identify concepts/learning work rather than claiming completed deployments.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/.
2. Create a **public** repository named `aman-yadav-portfolio` (or another name you prefer).
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root folder.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes and refresh the Pages settings. GitHub will show the public URL, usually:
   `https://YOUR-GITHUB-USERNAME.github.io/aman-yadav-portfolio/`

The URL depends on your GitHub username and repository name, so it cannot be finalized until you publish it. If you name the repository exactly `YOUR-GITHUB-USERNAME.github.io`, GitHub Pages can instead use that username-based URL.

## Updating
Edit the files and upload the changes to the same repository. Keep personal contact details public only if you are comfortable sharing them.
